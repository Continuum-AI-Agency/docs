title: "Elements"
description: "Save a model, product, character, or style once and reuse it across every generation, so it looks the same everywhere."
---

An **Element** is a saved subject — a model, a product, a character, a style — that you reuse across generations so it looks the same in everything you make. Save it once, then wire it into any generation or mention it by name.

## What's in an Element

| Field | What it holds |
| --- | --- |
| **Name** | What you'll call it, and what you `@`-mention. |
| **Category** | What kind of subject it is (see below). |
| **Images** | Up to 8 images of the same subject. |
| **Guidelines** | How the subject should and shouldn't appear. |
| **Rights basis** | Why you're allowed to use the subject. |

Categories: **Model**, **Character**, **Product**, **Object**, **Material**, **Setting**, **Location**, **Landscape**, **Style**, **Moodboard**, **Palette**, **Animation**, **Effect**, and **General**.

## Create an Element

<Steps>
<Step title="Open Elements">
On the canvas, select **Elements** in the toolbar, or open **Elements** in the [Library](/canvas/library) sidebar.
</Step>
<Step title="Choose New Element">
Name it, pick a category, and add up to 8 images of the same subject.
</Step>
<Step title="Add guidelines and rights">
Describe how the subject should appear, and record your rights basis.
</Step>
</Steps>

## Use an Element

- **On the canvas:** add an [Element node](/canvas/nodes/image) and connect it to a generation node as a reference.
- **In the Composer or a pipeline run:** type `@` and pick the Element.
- **From your AI assistant:** ask "Use our hero product Element for these three images." See [Make creative](/mcp/use-cases/creative).
