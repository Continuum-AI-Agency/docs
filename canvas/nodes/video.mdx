Video nodes live in the **Video** section of the **Add Node** menu.

## Video generation

The **Video Generation** node generates a clip with a video model. The menu lists one row per model, so you pick the model as you add the node. See [Models](/canvas/models) for each model's options.

**Inputs → outputs:** a prompt plus reference images or frames, depending on the model → video.

## Omni 1.1 Flash (Edit)

Generates a clip, then lets you chat to edit, extend, and upscale it into variations.

**Inputs → outputs:** a prompt, reference images, and a reference video → video.

## Extend video

The **Extend Video** node continues existing footage.

**Inputs → outputs:** a prompt and a video → video.

## Video decoder

The **Video Decoder** node breaks a video down frame by frame for creative analysis.

**Inputs → outputs:** video → text.

## Video editor

**Video Editor** node: a full editor to trim, split, and sequence clips and stills. It opens [Video Studio](/canvas/video-studio).

**Inputs → outputs:** a pool of media → video.

## HyperFrames agent

The **HyperFrames Agent** node creates video with an agent that builds it in HTML, using your media as references.

**Inputs → outputs:** a prompt and up to 20 images, videos, or audio files → video.

## Video reference

The **Video Reference** node brings a video file onto the canvas as an input.

**Inputs → outputs:** none → video.

## Try it

Ask Claude or ChatGPT:

- "Turn this product photo into a vertical video clip for Reels."
- "Make an 8-second 9:16 clip of our cold brew being poured over ice, using our hero product Element."

On the canvas, add **Extend Video** from the **Video** section, connect your clip and a **Text Block** that reads "slow push-in on the label", and choose **Run Node** to continue the shot.
