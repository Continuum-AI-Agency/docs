The canvas is a node-based workspace. You add nodes, connect outputs to inputs, and run the graph. Connections are typed, so the canvas only lets you make links that make sense.

## Add nodes

- **Right-click the canvas** to open **Canvas Actions**, then choose **Add Node**. Browse by section or type in **Search nodes…**.
- **Drag from an output handle onto empty canvas** to pick a node that accepts that output.
- **Drop files** from your computer onto the canvas to bring them in as references.
- Use the **side buttons** to browse your media library, import media from Instagram, search Unsplash photos, or browse styles.
- Ask the **Composer** to build a graph for you.

**Canvas Actions** also has **Load Workflow**, **Import from Instagram**, **Save** and **Save selection**, **Enforce brand book on selection**, view controls, and **Clear Canvas**.

## Connect nodes

Drag from one node's output handle to another node's input. Handles are typed — text, image, video, audio, document, or media — and only compatible handles connect. See [Nodes](/canvas/nodes/overview) for what each node takes and makes.

## Run a graph

| Control | What it does |
| --- | --- |
| **Run Flow** | Runs the graph, skipping nodes that haven't changed. |
| **Rerun all** | Regenerates every node from scratch. |
| **Abort** | Stops a run in progress. A progress bar shows how far it got. |
| **Run Node** | On a single node, runs just that node. |

Each node shows **Running**, **Done**, or **Error**. Outputs are saved to your [Library](/canvas/library).

## Save your work

The canvas autosaves a second after you stop making changes. The sync status shows where your work stands:

| Status | Meaning |
| --- | --- |
| `Saved` | Your work is saved. |
| `Saving...` | A save is in progress. |
| `Saved locally (offline)` | You're offline; changes sync when you reconnect. |
| `Connecting...` / `Live Disconnected` | The live connection is being restored. |
| `Sync Error` | A save failed. Keep the tab open and check your connection. |

To keep a graph you can reload, [save it as a workflow](/canvas/workflows).

## Workspaces

A workspace is a canvas tab for the brand. Create one with **New Workspace**, rename it with the pencil icon, or delete it. A workspace opened from the Planner carries a **Planner** badge, with **Back to Planner** and **Apply Back to Planner** to return your work to the draft.

## Collaborate

The canvas is multiplayer. Teammates in the same workspace appear in the avatar stack, and you see their named cursors live. A team chat keeps the conversation next to the work.

## The Composer

The Composer is the canvas agent. Describe a workflow and it builds the graph.

- Type `@` to bring in creative skills, Elements, or Library media.
- Type `/` for shortcuts, such as `/brand`, `/brand:colors`, `/brand:logo`, or `/nobrand`.
- Switch between **Thinking** and **Fast**.
- Attach up to three saved workflows as a starting point.
