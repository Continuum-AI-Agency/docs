<Note>This page is for the Continuum team. It's the checklist a design engineer runs when a client delivers an After Effects project, before integration begins.</Note>

Use this to confirm a hand-off meets the [preparation](/forge/after-effects/preparing) and [delivery](/forge/after-effects/delivery) requirements. If any check fails, return it to the client with the specific item before starting integration.

## Intake QA

| Check | What to verify |
| --- | --- |
| Separate layers | Each dynamic asset sits on its own layer — nothing flattened, merged, or pre-composed together. |
| Essential Graphics | Every dynamic asset is exposed in the **Essential Graphics** panel. |
| Composition scoping | For files with multiple compositions, each asset is exposed under its own composition. |
| Prices as text | Prices are live text layers on top of the backing design, not baked into images. |
| Longest-value space | Layouts hold the longest plausible value without overflow or clipping. |
| Presets applied | Continuum animation presets are applied to every dynamic asset — images, single-line text, and paragraph text. |
| Fonts included | All font files used by text layers are present (`.otf` / `.ttf`). |
| Asset access | For large domains, API access is provisioned for asset gathering. |
| Complete package | The delivery is a **Collect Files** folder with the project, footage, and fonts — not a bare `.aep`. |

## Common rejections

The most frequent reasons a hand-off goes back to the client:

- **Flattened dynamic assets** — two or more variable elements share one layer and can't be swapped independently.
- **Missing Essential Graphics exposure** — a dynamic asset exists but was never added to the panel, or was scoped to the wrong composition.
- **Prices baked into artwork** — a price is part of an image instead of a live text layer.
- **No headroom for longer values** — the design only fits the sample value and breaks on longer prices or copy.
- **Missing presets** — one or more dynamic assets have no animation preset applied.
- **Missing fonts** — fonts referenced but not included, or delivered as names only.
- **Bare project file** — a `.aep` sent without a **Collect Files** package.
