---
title: "Glossary"
description: "The Continuum-specific words the rest of the docs use, defined once each."
---

| Term | Definition |
| --- | --- |
| **Active brand** | The brand your session is working on. Switch it from the brand switcher, or ask your assistant to switch. |
| **AI Canvas** | The infinite node canvas where you generate and edit creative. Labeled **Canvas** in the app. |
| **Asset** | A raw file (an upload). Contrast with **creative**. |
| **Brand book** | Your living, AI-generated brand identity. It grounds generations and agents. Lives under **Settings → Brand Intelligence**. |
| **Brand kit** | The core identity: logo, brand colors, and typography. |
| **Brand readiness score** | A 0–100 measure of how complete your brand book is. Informational; blocks nothing. |
| **Brand Spy** | The competitor-intelligence workspace, in Creative+. |
| **Calendar** | The organic content calendar, also called the **Planner**, where drafts are planned and scheduled. |
| **Composer** | The canvas agent. Describe a workflow and it builds the graph. |
| **Connector** | The link that lets Claude, ChatGPT, or another assistant work in Continuum for you, over MCP. |
| **Creative** | Produced content — an image, video, or ad. |
| **Creative+** | The product line for making creative: the AI Canvas, pipelines, Elements, Video Studio, the Library, Forge, and Brand Spy. |
| **Creative skill** | A reusable creative-direction directive applied to a generation. |
| **Draft** | A planned organic post in the calendar. |
| **Element** | A saved model, product, character, or style that stays consistent across generations. |
| **Forge** | Turns a design file into a template, then renders many versions of it. |
| **Grounding** | Steering a generation with your brand book, creative direction, and design system. |
| **Jaina** | The ads analyst agent, in Performance+. |
| **Library** | Your brand's searchable home for all media. |
| **MCP** | Model Context Protocol, the open standard Continuum's connector uses. |
| **Node** | A single block on the canvas: a prompt, reference, generator, edit, or delivery step. |
| **Optimizer** | Paid optimization. It proposes budget moves across portfolios for you to approve. |
| **Organic agent** | Your social strategist agent, in Organic+. |
| **Organic+** | The product line for organic social: the Organic agent, the calendar, publishing, and analytics. |
| **Performance+** | The product line for paid media: Jaina, paid analytics, and Paid optimization. |
| **Pipeline** | A canvas graph published with declared inputs, so anyone can run it with new material. |
| **Portfolio** | A group of ad sets the Optimizer works over. |
| **Technique** | A saved selection of canvas nodes you can drop into any graph. |
| **Video Studio** | The timeline video editor. |
| **Workflow** | A saved canvas graph you can reload and rerun. |
| **Workspace** | A canvas tab for the brand. |
