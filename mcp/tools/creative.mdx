### `studio_workflow`

Builds, edits, runs, saves, and lists canvas workflows.

**Good to know:**

- Canvas reads and builds work on a workspace (`room_id`). `target: "library"` saves a reusable template instead.
- `delete` and `workspace_delete` are two-phase. A brand holds at most three workspaces.
- To make the creative for a Planner draft, pass `source_draft_id` to `build`.
- `run` without a `room_id` returns `needs_workspace`: ask the person to open the canvas in Continuum, then retry.

| Contract | Behavior |
| --- | --- |
| Changes things | Yes |
| Listed in your assistant | Always. |
| Role | Operator or higher, for every action. |
| Needs | An active brand. |
| Confirmation | Writes preview first and return a `confirm_token` with `expires_at`. Confirm with that token after the person says yes. |
| Completion | Returns right away. Longer work continues as a job; read the id in the result. |
| Retry | Not idempotent. Check the current state before retrying. |
| Rate limit | Canvas runs: 10 an hour, per brand. See [Limits](/mcp/reference#limits). |

### `pipeline_invoke`

Runs a pipeline, up to 10 versions per request.

**Good to know:**

- Returns one receipt per run right away, usually `queued`. Read progress with `pipeline_run_status`.
- Reusing the same `idempotency_key` for the exact same request is safe. Use a new key for a new request.

| Contract | Behavior |
| --- | --- |
| Changes things | Yes |
| Listed in your assistant | Always. |
| Role | Operator or higher, because a run can spend. |
| Needs | An active brand. |
| Confirmation | None. The call runs when made. |
| Completion | Returns right away. Longer work continues as a job; read the id in the result. |
| Retry | Retry with the same `idempotency_key` to avoid duplicates. |
| Rate limit | Up to 10 runs in one call. See [Limits](/mcp/reference#limits). |

**Inputs:**

| Input | Type | Required | About |
| --- | --- | --- | --- |
| `pipeline_id` | string | Yes | `pipeline_id` returned by `pipeline_describe`. |
| `family_id` | string | Yes | identity.`family_id` returned by `pipeline_describe`. |
| `revision` | integer | Yes | identity.revision returned by `pipeline_describe`. |
| `contract_hash` | string | Yes | identity.`contract_hash` returned by `pipeline_describe`. |
| `idempotency_key` | string | Yes | Stable caller-generated key. Reuse it only to retry this exact invocation. In a batch, run i is keyed `<idempotency_key>:<i>`. |
| `text_inputs` | array | No | — |
| `asset_inputs` | array | No | — |
| `element_inputs` | array | No | — |
| `runs` | array | No | Up to 10 variations in one call, each with its own input lists. Use instead of the top-level input lists, never together with them. |
