### `media_capture_url`

Turns a public web page into a screenshot or a scroll-through video in your Library.

**Good to know:**

- Public https pages only: sign-in walls, private networks, and plain http are refused. A capture takes 10 to 40 seconds and returns Library asset ids.

| Contract | Behavior |
| --- | --- |
| Changes things | Yes |
| Listed in your assistant | Always. |
| Role | Operator or higher |
| Needs | An active brand. |
| Confirmation | None. The call runs when made. |
| Completion | Returns the result in the same call. |
| Retry | Safe to retry: repeating the call gives the same result. |

**Inputs:**

| Input | Type | Required | About |
| --- | --- | --- | --- |
| `url` | string | Yes | The public https page to capture (product, reviews, pricing, press article, demo). |
| `device` | string | No | reel = 1080x1920 (default), iphone = 1179x2556, desktop = 1920x1080. One of `reel`, `iphone`, `desktop`. |
| `outputs` | array | No | screenshot = a PNG still; recording = an MP4 scroll-through. Default both. |
| `full_page` | boolean | No | Screenshot the whole page instead of one screen (capped at 16,000 px tall). |
| `duration_sec` | number | No | Recording length in seconds (2-15, default 8, 30 fps). |
| `highlight_selector` | string | No | CSS selector of one element to outline; the capture scrolls to it. |
| `highlight_text` | string | No | Visible text to outline instead of a selector (e.g. "4.9 stars"). |
| `locale` | string | No | Browser language, e.g. es-CL, so a localized site serves that language. Default en-US. |
