### `planner_manage`

Reads and proposes a week of posts, approves it, reschedules and copies posts, and attaches media.

**Good to know:**

- `propose_week` runs as a job. `proposal_status` returns its `plan_id` and a `pending_approval_token` that lasts 24 hours.
- `approve_week` commits the whole week in one step and is safe to repeat.

| Contract | Behavior |
| --- | --- |
| Changes things | Yes |
| Listed in your assistant | Always. |
| Role | Any brand member |
| Needs | An active brand |
| Confirmation | Writes preview first and return a `confirm_token` with `expires_at`. Confirm with that token after the person says yes. |
| Completion | Returns right away. Longer work continues as a job; read the id in the result. |
| Retry | Each `confirm_token` works once. Preview again to retry. |

### `content_create`

Drafts, approves, and publishes posts, and deletes drafts.
